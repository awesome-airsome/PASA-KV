# 开源网站包

本目录包含匿名方法实现、配套论文图表和可直接作为 GitHub Pages 起点的静态主页 index.html。

## 目录

- index.html：项目主页，展示方法概述、流程、图表和代码入口。
- code/PASAKV/：2026-09-27 整理的匿名参考实现，含 Python 包、配置、测试、英中 README、NOTICE 和匿名化审查记录。
- assets/figures/：从图表归档整理出的 SVG 矢量图，以及 Figure 4 管线图 PNG。
- figure_sources/：整套可编辑图表 PPTX。
